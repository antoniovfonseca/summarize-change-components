## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Please report vulnerabilities privately by emailing [antfonseca@clarku.edu](mailto:antfonseca@clarku.edu) or through the repository's [GitHub Security Advisories page](https://github.com/antoniovfonseca/summarize-change-components/security/advisories/new).

Please include:

- A clear description of the vulnerability;
- The affected notebook, file, component, or version;
- Steps to reproduce the issue;
- The potential impact;
- Any suggested mitigation.

Do not include API keys, service-account credentials, access tokens, private bucket names, or other secrets in the report. If a secret may have been exposed, revoke or rotate it immediately and mention that fact in the private report.

We will acknowledge valid reports within 7 days and provide an initial assessment within 14 days. We will coordinate disclosure and credit reporters when appropriate.
